# Mock.AI Backend

AI-powered mock test application backend.

## Instructions

1. Activate the virtual environment (I have already created it for you):
```bash
source venv/bin/activate
```

2. Run the application:
```bash
uvicorn main:app --reload
```

3. Open Swagger UI to test the API:
[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
