| `REG-SSC-02` | **Wiped question stems** | Encountering an option token truncated or cleared preceding question stem nodes. | `BoundaryDetector` aggregates multi-line text runs up to option start; stem node IDs are immutable. | **PASS** |
| `REG-SSC-03` | **Identical option allocation** | Options under Q1 leaked into Q2 or were duplicated between adjacent questions. | `OptionClassifier` strictly binds option candidates to the nearest preceding `QuestionAnchor` within spatial column boundaries; zero cross-question allocation. | **PASS** |
| `REG-SSC-04` | **Passage / stimulus leakage** | Reading comprehension text was swallowed into Q1's stem, leaving subsequent questions disconnected. | `StimulusDetector` groups directive and stimulus body into `StimulusCandidate`; questions reference via `stimulusRefIds` with zero content cloning. | **PASS** |
| `REG-SSC-05` | **Answer-key / question identity shift** | Ingestion pipeline conflated serial question index with official ID and answer key. | QuestionGraph enforces total identity separation: `sourceQuestionNumber`, `officialQuestionId`, `candidateDisplayOrder`, `sourceOrder`. Canonical IDs and answer keys are strictly prohibited. | **PASS** |
| `REG-SSC-06` | **TCS response status block isolation** | TCS response metadata tables (`Question ID : 123456`, `Status : Answered`) corrupted stem text. | `TokenClassifier` and `BoundaryDetector` detect metadata table patterns, route `Question ID` to `officialQuestionId`, and isolate the block from question stems. | **PASS** |
| `REG-GATE-01` | **Flattened mathematics** | Mathematical exponents, superscripts, and subscripts were flattened into lossy plain strings. | `MathDetector` groups mathematical glyph runs into `MathCandidate` preserving physical node IDs, bounding boxes, and relative baseline offsets without stringification. | **PASS** |
| `REG-GATE-02` | **Duplicated option images** | Option diagrams were assigned identical hashes and overwritten across option cards. | `DiagramDetector` generates distinct diagram candidates mapped to unique physical image/vector object IDs. | **PASS** |
| `REG-GATE-03` | **Flattened Column-I / Column-II matching grids** | Two-column matching questions had rows flattened into continuous text, destroying pairing layout. | `TableDetector` isolates grid layout into `TableCandidate` with cell coordinates and preserves row/column alignment. | **PASS** |
| `REG-GATE-04` | **Diagram-label leakage** | Text labels inside circuit diagrams or geometric figures detached and leaked into question stem. | `DiagramDetector` detects text nodes fully contained within diagram bounding boxes and binds them to the diagram candidate. | **PASS** |
| `REG-GATE-05` | **Duplicate diagrams across questions** | Multi-subquestion diagrams were re-extracted and duplicated on disk. | QuestionGraph stores diagram candidates once and allows multiple `QuestionCandidate` nodes to reference the same `diagramRefId`. | **PASS** |

## False-Positive and False-Negative Accounting

Forensic examination of real-world segmentation revealed the following metrics across the 24-page audit sample:

1. **Question Number False-Positives (Tokens incorrectly classified as Question Numbers):**
   - **Count:** 0.
   - **Mechanism:** Mitigated by `previousQuestionHasExplicitPrefix` tracking in `TokenClassifier` and margin/header bounds. On SSC CHSL, bare numeric options $1 \dots 4$ are strictly precluded from matching sequential question numbering.
2. **Question Number False-Negatives (True questions missed):**
   - **Count:** 0 in the 24-page sample. All explicit and sequential margin questions were detected.
3. **Option False-Positives (Stem text incorrectly classified as options):**
   - **Count:** 4 in UPSC sample where multi-statement lists (`(a)`, `(b)` inside stem clauses) generated alternative option candidates.
   - **Mitigation:** Retained as competing hypotheses in `hypotheses` with ambiguity records; neither hypothesis destroyed source text.
4. **Option False-Negatives (True options dropped):**
   - **Count:** 0.
5. **Diagram False-Positives (Watermarks/divider lines attached as diagrams):**
