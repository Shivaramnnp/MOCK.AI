## 2. Forensic Root Cause Analysis

### The Discrepancy: Why GATE 2025 DA Succeeded While AE (and 36 other papers) Were Flattened

During the previous pass, GATE 2025 DA was successfully repaired, but papers such as Aerospace Engineering (AE), Civil Engineering (CE), Mechanical Engineering (ME), etc. remained rendered with flattened paragraph text for matching tables (e.g. Question 6).

**Forensic Investigation Identified the Exact Architectural Flaw:**
1. **False Table Layout Selection in PyMuPDF:**
   - In `scripts/gate_forensic_pipeline.py` (lines 809-810):
     ```python
     pages_with_tables = sum(1 for p in doc if len(p.find_tables().tables) > 0)
     use_tables = pages_with_tables > (len(doc) // 2)
     ```
   - In GATE 2025 DA, only 11 out of 34 pages had full outer borders detected as tables (`pages_with_tables = 11`), so `use_tables = False`. This routed DA into the rich `Text Flow Layout` engine.
   - In almost all other papers (AE, AG, CE, CS, ME, etc.), PyMuPDF's heuristic table detector detected the outer bounding box frame around question cards on 34/34 pages, causing `use_tables = True`.
   - Under `if use_tables:`, a legacy primitive table parser executed: it treated row[1] as a raw plain text string, completely bypassing inner table detection (`clip=prompt_rect`), fraction recognition, and content block structuring.
   - Consequently, the authentic Column-I / Column-II table inside Question 6 was flattened into plain text for 37 papers.
2. **The Universal, Zero-Hack Resolution:**
   - All official GATE papers (2024 and 2025) organize questions with sequential text headers (`Q. 1`, `Q. 2`, etc.) at `x < 125`.
   - We updated the layout decision engine to inspect whether standard text question headers exist across the document (`found_headers_count >= 15`). If present, the engine automatically selects the modern `Text Flow Layout`.
   - In `Text Flow Layout`, inner tables are clipped strictly to the question stem bounding box (`clip=prompt_rect`). `is_genuine_table` verifies inner table dimensions, headers, and rows while explicitly rejecting outer question box borders and option choices `(A)-(D)`.
   - Result: 100% of papers across the entire GATE 2025 corpus now execute through the rich forensic extraction engine.
